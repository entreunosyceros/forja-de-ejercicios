Forja de ejercicios genera problemas prácticos de informática, los corrige de forma automática y opcionalmente te deja practicar en un contenedor Docker. Esta página explica el flujo completo sin necesidad de iniciar sesión.

¿Qué es?

Es una aplicación web (Spring Boot) que delega en Python la generación y la evaluación de ejercicios. Cada alumno recibe enunciados distintos; al corregir se guardan nota, tiempo y estadísticas de uso.

  • Portada: elige módulo (POO, SQL, Docker, apuntes del profesor, banco verificado…).
  • Apuntes PDF: sube ficheros desde la portada (Subir e indexar) o colócalos en documentacion/ y pulsa Actualizar apuntes.
  • Ejercicio: lees el enunciado, escribes comandos o código en un cuadro de texto.
  • Corrección: el sistema comprueba criterios verificables y muestra nota y pistas.
  • PDF / JSON: puedes descargar el enunciado; el profesor puede ver la solución de referencia.

Flujo del alumno

  1. Entras en /login con tu usuario y contraseña (demo: alumno / practica).
  2. En la portada pulsas Empezar ahora, un módulo concreto o un tema de apuntes indexados.
  3. La web ejecuta generador.py y muestra el ejercicio con tu nombre y la fecha de inicio.
  4. Escribes tu respuesta y pulsas Enviar y corregir (hay temporizador orientativo, sin penalización).
  5. evaluador.py devuelve nota (0–10), criterios cumplidos o no, y enlace a apuntes si el ejercicio venía de un PDF.
  6. Puedes pedir Otro ejercicio del mismo módulo o volver al inicio; tus últimos resultados y medallas se guardan en el navegador.

Los ejercicios generados con IA desde PDF muestran una pantalla de carga mientras se prepara la propuesta.

Tipos de ejercicio

TipoOrigen¿Necesita clave API?
A — Plantilla generador.py (POO, SQL, redes, Docker, Git…) No
B — Apuntes + IA PDF en documentacion/ → índice → fragmento → IA → modelo_ejercicio.py Sí
Banco JSON en banco/aprobados/ (manual o aprobado por el profesor) No

La IA no escribe el ejercicio final ni inventa expresiones regulares. Solo propone un JSON con tema, pregunta y palabras_clave; el sistema construye enunciado y criterios y valida que las claves aparezcan en el fragmento del PDF.

PDF → indexador → fragmento → propuesta IA
     → modelo_ejercicio.py → escenario JSON → pantalla del alumno

Cómo se corrige

Cada ejercicio lleva una lista de criterios con peso. El evaluador comprueba la respuesta del alumno:

  • regex — expresión regular (módulos plantilla, ejercicios del banco escritos a mano).
  • contiene_todos — deben aparecer todos los términos (orden irrelevante).
  • contiene_alguno — basta con un sinónimo de la lista (p. ej. nginx o nginx:latest).

La nota es proporcional al peso de criterios cumplidos; ≥ 5 aprueba. Las palabras clave vagas («configurar», «servidor») se rechazan al generar ejercicios desde apuntes.

Banco de ejercicios y modo profesor

Entra con la cuenta profesor y revisa sin JSON crudo:

  • banco/pendientes/ — propuestas de IA si gemini-guardar-pendientes=true.
  • /profesor/revisar — tabla comparativa, pruebas automáticas y paquete ZIP.
  • vocabulario_claves.json → alias_comandos (sinónimos como docker container run).
python3 herramientas/revision_profesor.py --id <id>
python3 herramientas/paquete_entrega.py <id>
python3 herramientas/revisar_banco.py aprobar <id>

Práctica en Docker (opcional)

El enunciado se corrige en la web (arrancada con ./arrancar-web.sh en el host). Para practicar con herramientas reales, levanta solo el servicio practica:

cd examenforge
docker compose up -d --build practica
docker exec -it forjaexamenes-practica bash

Usuario del contenedor: alumno / practica (distinto del login web). Archivos de práctica en examenforge/datos-practica/.

Cuenta, perfil y estadísticas

  • Perfil (/perfil): cambia nombre visible, usuario de acceso y contraseña.
  • El nombre visible sale en ejercicios y PDF; el login identifica tus estadísticas en el servidor.
  • En la portada: panel de progreso (historial, ranking por módulo, medallas) en el navegador.
  • Al final: Tus estadísticas de uso (ejercicios hechos, nota media, racha, tiempo, desglose por módulo).
