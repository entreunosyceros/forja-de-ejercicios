Autoría

Este sistema ha sido diseñado, implementado y mantenido por entreunosyceros como plataforma de práctica evaluada para módulos de administración de sistemas, bases de datos, programación y documentación técnica.

Incluye interfaz web (Spring Boot), motor de generación y corrección (Python), banco de ejercicios verificados, seguimiento del profesor, exportación de resultados y ejercicios con IA a partir de apuntes PDF.

Componentes y reconocimientos

  • Spring Boot — aplicación web y API REST.
  • Python — generador.py, evaluador.py, indexación de PDFs.
  • Google Gemini — generación opcional de ejercicios desde apuntes (clave del usuario).
  • Apache PDFBox — exportación de ejercicios y correcciones a PDF.
  • Docker — entorno de práctica aislado para módulos de sistemas.
