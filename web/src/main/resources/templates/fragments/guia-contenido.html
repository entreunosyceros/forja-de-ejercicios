Clave API de Gemini

Necesaria solo para ejercicios generados desde apuntes PDF. Los módulos poo, docker, redes, etc. funcionan sin ella.

✅ La aplicación detecta una clave configurada.

⚠️ Aún no hay clave válida. Sigue estos pasos:

  1. Entra en Google AI Studio → API keys e inicia sesión con tu cuenta Google.
  2. Pulsa Create API key y copia la clave (suele empezar por AIza…).
  3. En la carpeta del proyecto, crea o edita el fichero examenforge/.env:
cp .env.example .env
# Edita .env y pega tu clave REAL (sin comillas):
GEMINI_API_KEY=AIzaSy_tu_clave_aqui
FORJAEXAMENES_GEMINI_MODEL=gemini-2.5-flash

No subas .env a GitHub. Usa .env.example solo como plantilla.

  1. Instala dependencias Python (solo la primera vez):
cd examenforge
pip install -r requirements-docs.txt
  1. Reinicia la aplicación (./arrancar-web.sh). En la portada debe desaparecer el aviso de clave pendiente.
Si aparece error de cuota (429)

La clave es válida pero Google limita peticiones. Usa el modelo gemini-2.5-flash en .env o espera un minuto y reintenta.

Añadir apuntes (PDF)

Cada carpeta bajo documentacion/ genera un módulo docs_<tema> en la portada, sin tocar Java.

examenforge/documentacion/
├── docker/
│   └── apuntes.pdf          →  docs_docker
├── ansible/
│   └── intro.pdf            →  docs_ansible
└── forense/
    └── modulos.pdf          →  docs_forense
  1. Copia tus PDF en documentacion/<nombre-tema>/, o súbelos desde la portada (sección Subir apuntes).
  2. Indexa (elige una opción):
    • Reinicia la web (auto-indexación al arrancar), o
    • En la portada: Actualizar apuntes, o
    • Terminal: python3 indexador_docs.py
  3. En la portada, sección Apuntes del profesor, elige tema o capítulo.

Subcarpetas dentro de un tema = capítulos (p. ej. documentacion/docker/volumenes/).

Añadir un nuevo tipo de ejercicio

Los ejercicios clásicos viven en Python; la web solo enlaza módulos ya registrados.

  1. En generador.py, crea una función que devuelva un diccionario con titulo, enunciado, criterios (regex) y solucion_referencia.
  2. Regístrala en las tuplas MODULOS y GENERADORES del mismo fichero.
  3. Prueba en terminal:
python3 generador.py -m mi_modulo --formateado
  1. Añade un botón en web/src/main/resources/templates/inicio.html:
<a class="btn btn-secondary"
   th:href="@{/ejercicio/nuevo(modulo='mi_modulo')}">Mi módulo</a>
  1. Reinicia la aplicación. La corrección la hace evaluador.py con los criterios regex del JSON generado.

Para ejercicios desde PDF + IA no hace falta editar generador.py: basta indexar apuntes y configurar Gemini.
